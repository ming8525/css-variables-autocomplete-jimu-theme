# css-variables-autocomplete-jimu-theme README

## Features

Provide auto-completion for CSS variables in the `jimu-theme`.

## How to use

Once the plugin is installed, no configuration is needed.  
Type **`--`** to trigger autocomplete suggestions for CSS variables. You can continue typing keywords to further filter the suggestions.
Selecting a suggested variable will automatically complete it in the format `var(--{variable})`.

## Extension Settings

This extension contributes the following settings:

* `cssVariablesAutocompleteJimuTheme.filePath`: Path to the CSS variables file.
* `cssVariablesAutocompleteJimuTheme.languages`: List of languages in which the autocomplete should be enabled.
